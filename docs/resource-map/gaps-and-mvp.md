# 能力缺口与最简单的 MVP

日期：2026-10-11。本文是研究结论与待确认的实现方案，没有实现算法，也没有启动新计算。

## 应该直接用、改造还是自研

**建议基于现有方案二次开发。** 现有框架已覆盖梁运动学、装配、积分和基础接触，全部自研会重复这些工作；但是本库没有一个项目能直接提供金丝的截面塑性、供丝历史、瓷嘴接触与连接／卸载全流程。

Chrono 保留为首选通用力学底座参考；正式采用前，先证明专用截面状态可以稳定接入 C++ 路径。EXUDYN 是二维几何与送丝约束的备选，需另行设计材料历史提交机制。PyElastica 适合作杆数组、显式积分和接触算法的学习对照，不能直接当作塑性成弧求解器。项目之间共享的是设计参考，不能直接混用内部状态和离散公式。

## 最简单可验证的方案

**范围：单根金丝、给定平面瓷嘴轨迹、大转动弹塑性梁、等效第二端连接、解除工具作用后的残余弧形。** 不在首版加入自动轨迹优化、三维复杂扭转、超声键合区微结构、断裂或机器学习替代本构。

1. **运动学**：选用一种平面大转动梁离散，保留轴向伸长和弯曲；三维偏移或扭转明显时再扩展三维梁。梁无法可靠解释的出口压扁／局部接触区域，用独立实体子模型评估。
2. **材料**：圆截面纤维积分，初版采用有历史的弹塑性模型。线性随动硬化可作为反向加载基线；是否需要更复杂组合硬化，由适用数据与验证决定。不能从银铜钢线或板材论文直接拿金丝参数。
3. **供丝**：优先评估预建完整材料线与有限储丝段，在瓷嘴中滑动的方案。它可减少动态增单元和 ALE 塑性状态输运工作；必须控制储丝段边界与张力，验证储丝长度敏感性。理想导向仅用于最初运动学检查，输出有摩擦成形预测时需加入相应接触。
4. **工具与接触**：平面内孔及出口圆角的刚性轮廓，考虑线径偏置；先用便于验证的接触模型。IPC Toolkit 列为后续接触候选，首版不因采用 IPC 而强制改变整套积分方案。
5. **工序事件**：按材料身份在当前变形位置添加第二端约束，继承材料历史；再分阶段解除瓷嘴／尾段作用。连接刚度与转角约束必须明确，等效连接不代表已模拟真实焊接冶金。
6. **求解方式**：在所选框架中先比较能够接入历史本构的积分路径。真实工艺速度重要时保留动力效应；若采用慢加载近似静态，需同时检查加载时间、能量、阻尼、步长及最终线形敏感性。本文不预先承诺显式一定更快或隐式一定收敛。
7. **输出**：按材料弧长保存全过程中心线、曲率、截面内变量、反力与能量；区分约束仍存在时的形状和解除工具作用后的残余形状。

没有独立落点检查门槛。用户已要求跳过该检查，后续调用路径需实际跳过检查入口，状态记 `skipped_by_user`，不能记作通过。

## 与 Abaqus 结果如何对照

先比较同一几何、材料、轨迹时序、供丝、边界约束和工序事件下的模型，再研究二维梁、三维梁或实体之间的差别。二维平面应力、二维平面应变与圆截面梁不是同一种物理假设，不能因为都是二维就视为等价。L026 的二维有限元方法需要按原文单独辨认；它不能直接证明二维平面应力适合所有金丝成弧。

能完成求解只说明该数值方案完成了计算；材料、接触与工序误差仍需独立验证。用 Abaqus 作数值参照时，不把它当作实验真值。本公共库只记录通用对照方法，不上传私有输入、设备轨迹、计算结果或日志。

进入完整成弧组合前，依次完成：材料单点与截面 → 单梁正反弯曲 → 接触滑动 → 供丝身份追踪 → 连接与解除作用 → 全工序和参数敏感性。此顺序供用户确认后开发使用，不表示已经授权执行。
